## 발견한 문제

- 실제 관찰한 문제만 기록한다.

## 조치

- 수정한 프롬프트·코드와 수정 이유를 기록한다.

## 평가 한계

- 가상 자료와 소수 표본으로 확인한 결과다.
- 실제 금융업무 담당자의 독립 검증은 수행하지 않았다.
- 이번 결과로 전체 답변 정확도나 운영 적합성을 추정하지 않는다.
